Checking if Git is installed:
git --version

Viewing all cammits:
git log

Viewing file status and changes:
git status

Adding cammit:
git commit -m ""

Return to last cammit:
git reset --hard HEAD

Deleting the last commit without losing the current code:
git reset --soft HEAD~1

Shows all Git-tracked files:
git ls-files

Adding files for commits:
git add

Push changes to the remote repository:
git push
